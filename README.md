# Spring Boot

Repositorio en donde creamos una tienda usando como referencia el libro de "Spring Boot in Action de Craig Wells" siguiendo los contenidos del libro.

A traves de este repositorio busco mostrar mis avances en el uso de spring boot creando una aplicacion practica en donde aplicamos cada parte del libro

Se ha refactorizado para usar tanto un auth-server que se encargue de manejar los login y generar el token de la aplicacion, ademas que usa RSA para generar la firma digital
